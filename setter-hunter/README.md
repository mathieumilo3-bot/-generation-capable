# Setter Hunter

Independent recruiting cockpit for sourcing, qualifying and managing setter candidates.

## V1
- Candidate CRM
- AI-ready scoring model
- Multi-channel source tracking
- Outreach drafts and follow-up queue
- Applications and recruitment pipeline
- Setter performance metrics
- Compliance-first workflow: official APIs/authorized actions; no credential scraping or platform bypassing.

## Flow
Discovery -> Qualification -> Outreach Draft -> Contact -> Reply -> Application -> Test -> Interview -> Hired -> Performance.
