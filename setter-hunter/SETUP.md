# Setter Hunter setup

1. Create/connect the independent Setter Hunter app in Netlify.
2. Connect a database and apply `data-model.sql`.
3. Add the AI scoring/message-generation service.
4. Connect only official/authorized social APIs and OAuth permissions.
5. Configure source ingestion and deduplication.
6. Configure the outreach approval queue.
7. Configure candidate application/test forms.
8. Add analytics for booked meetings and sales.

The system should never require storing social passwords. Use OAuth/tokens supplied by the platform integrations.
