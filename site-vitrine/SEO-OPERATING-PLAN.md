# GC — SEO Operating Plan

Ce document décrit comment faire progresser les pages de gc-agence.com après publication. Il complète SEO-KEYWORD-MAP.md.

## Objectif
Maximiser les **opportunités commerciales issues de Google**, pas seulement le volume de trafic.

## 1. Ordre de priorité Search Console

Chaque semaine, classer les requêtes et pages selon ces zones :

### Zone A — positions 4 à 15
Priorité maximale. Ces pages sont déjà proches de la première page ou du haut de page.
Actions :
- enrichir le contenu sur les sous-intentions réellement vues dans Search Console ;
- renforcer les liens internes vers la page ;
- améliorer title et description si le CTR est faible ;
- ajouter une FAQ utile si une objection manque ;
- ajouter une preuve réelle quand elle existe ;
- obtenir des liens externes pertinents.

### Zone B — positions 16 à 40
Priorité élevée si les impressions augmentent.
Actions :
- vérifier que l'intention de la requête correspond bien à la page ;
- couvrir les sous-sujets manquants ;
- créer des guides de soutien puis les relier à la page commerciale ;
- renforcer le maillage depuis les pages de secteur et ressources.

### Zone C — positions 40+
Ne pas réécrire automatiquement.
Actions :
- vérifier si la requête mérite réellement une page dédiée ;
- fusionner les contenus qui se cannibalisent ;
- créer une nouvelle page uniquement si l'intention est distincte.

### Zone D — impressions sans clic
Analyser le CTR.
Actions :
- titre plus précis ;
- bénéfice ou cible mieux exprimé ;
- description plus proche de la requête ;
- vérifier que la page répond réellement à ce que Google affiche.

## 2. KPI à suivre
- impressions Google ;
- clics organiques ;
- position moyenne par requête et par page ;
- CTR ;
- formulaires démarrés ;
- diagnostics envoyés ;
- rendez-vous ;
- source de la demande ;
- requête ou page d'entrée quand disponible.

Le trafic seul n'est jamais le KPI final.

## 3. Priorités commerciales
Ordre de travail par valeur potentielle :
1. création site internet / refonte ;
2. agence web / agence marketing digital ;
3. audit site / audit SEO / audit marketing digital ;
4. référencement local / Google Business ;
5. génération de leads / acquisition ;
6. Google Ads / Meta Ads ;
7. marketing digital PME / artisan / BTP ;
8. génération de leads B2B / acquisition B2B ;
9. landing pages / tunnels / conversion ;
10. verticales à forte valeur : BTP, dentaire, nettoyage, événementiel, restaurants.

## 4. Règle anti-cannibalisation
Avant de créer une nouvelle URL :
- rechercher si une page actuelle couvre déjà l'intention ;
- comparer la SERP et le besoin utilisateur ;
- enrichir la page existante si l'intention est proche ;
- créer une page séparée uniquement lorsque la réponse attendue est réellement différente.

## 5. Règle locale
Pas de génération massive de pages ville clonées.
Créer une page locale seulement si :
- GC sert réellement cette zone ;
- le contenu peut être spécifique ;
- la page peut citer des éléments vérifiables propres à la zone ;
- elle apporte plus qu'un simple remplacement du nom de ville.

## 6. Maillage interne
Chaque page commerciale doit recevoir des liens depuis :
- le hub /solutions ;
- au moins une page de secteur pertinente ;
- un ou plusieurs guides ;
- les pages commerciales proches.

Chaque guide doit pointer vers une prochaine étape commerciale pertinente.

## 7. Backlinks et autorité
Priorité aux liens réels :
- annuaires professionnels qualitatifs ;
- partenaires ;
- clients avec accord ;
- interviews ;
- publications métier ;
- associations professionnelles ;
- profils d'entreprise cohérents ;
- études ou ressources réellement citables.

Éviter l'achat massif de liens, les réseaux artificiels et les ancres exactes répétées.

## 8. Cadence éditoriale
Chaque nouveau contenu doit venir d'au moins un signal :
- requête Search Console ;
- question prospect ;
- objection commerciale ;
- sujet à forte intention observé dans les résultats Google ;
- service ou secteur réellement vendu.

Objectif : 2 à 4 contenus solides par semaine plutôt qu'un volume artificiel.

## 9. Boucle hebdomadaire
1. exporter les nouvelles requêtes Search Console ;
2. repérer les pages avec impressions en hausse ;
3. sélectionner 3 à 5 opportunités ;
4. améliorer contenu + maillage + snippet ;
5. mesurer les conversions ;
6. garder un journal des changements ;
7. attendre assez de données avant de conclure.

## 10. Condition pour accélérer
Lorsqu'une page entre dans les positions 4 à 15 avec un volume d'impressions croissant :
- elle devient page prioritaire ;
- enrichir les sections qui correspondent aux vraies requêtes ;
- publier 1 à 3 guides satellites utiles ;
- créer des liens internes contextuels supplémentaires ;
- rechercher des backlinks sectoriels ;
- améliorer le CTR sans promesse trompeuse.

## 11. Search Console
Le site supporte NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION.
Une fois la propriété connectée :
- soumettre https://gc-agence.com/sitemap.xml ;
- inspecter les pages commerciales prioritaires ;
- vérifier indexation et canonicals ;
- suivre les requêtes réelles plutôt que des listes théoriques.

## 12. Règle finale
Aucune action SEO ne doit dégrader la qualité du site pour l'utilisateur.
Une page créée uniquement pour un mot-clé, sans information distincte, n'est pas publiée.
