# Site vitrine — Dr Hossame Bakraoui (chirurgien-dentiste, Meknès)

Site statique (HTML/CSS/JS, aucune dépendance). Ouvrir `index.html` ou servir le dossier tel quel (Netlify, GitHub Pages…).

## À personnaliser avant mise en ligne
- **Numéro WhatsApp** : `WHATSAPP_NUMBER` en haut de `script.js` (format `212XXXXXXXXX`, sans `+`).
- **Horaires** et **adresse exacte** : section `#rdv` dans `index.html`.
- **Photos** : `assets/img/` — les images actuelles sont issues de son profil Instagram (basse résolution).
  Remplacer par des photos HD (mêmes noms de fichiers) : `hossame-portrait.png` (rond, fond transparent ou carré),
  `hossame-consultation.jpg`, `smile-detail.jpg`, `video-siwak.jpg`, `video-radio.jpg`.
- **Avant / après** : illustration vectorielle générée dans `script.js` (`smileSVG`) — à remplacer par de vrais cas (avec accord patient).
- **Liste des soins / FAQ** : à valider avec le Dr Bakraoui.
- Langues : FR par défaut, bouton FR / عر pour l'arabe (textes en attributs `data-ar`).
