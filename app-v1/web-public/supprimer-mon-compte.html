Supprimer mon compte et mes données

Cette page est l’URL de suppression de compte déclarée dans la console Google Play.

Depuis l’application

  1. Ouvrez l’application et connectez-vous.
  2. Allez dans Compte → Confidentialité → Supprimer mon compte.
  3. Confirmez, puis saisissez le code reçu par e-mail.

Supprimer depuis le web

Ce qui est supprimé

Vos projets, vos fichiers (vidéos envoyées, vidéos produites, miniatures), votre profil et vos données de connexion. Si vous avez utilisé « Se connecter avec Apple », l’accès Apple est également révoqué.

Ce qui est conservé

Les justificatifs de paiement (montants et dates) sont conservés sans lien avec votre identité, car la loi nous impose de tenir notre comptabilité. [DURÉE LÉGALE À CONFIRMER]

Vous ne pouvez plus accéder à l’application ?

Écrivez-nous depuis l’adresse du compte à support@example.com : nous procéderons à la suppression.
