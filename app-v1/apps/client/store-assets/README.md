# Captures App Store (iPhone 6,9", 1320 × 2868)

`ios/6.9/01..06.png` : accueil, choix du mode, durée et prix, récapitulatif, création en cours, résultat.

**Ce sont des captures de travail**, générées depuis la version web avec un backend simulé
(`scripts` éphémères) : l'écran 06 montre une mire de test à la place d'une vraie vidéo.
Avant la soumission, remplacez-les par des captures réelles faites sur un build de test
(simulateur iPhone 17 Pro Max ou appareil), avec une vraie vidéo produite, en gardant les mêmes noms de fichiers.
Apple rejette les captures qui ne reflètent pas l'app réelle (guideline 2.3.3).
